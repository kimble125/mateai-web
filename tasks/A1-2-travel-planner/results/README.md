# 실행 결과 예시

이 폴더의 JSON·Markdown은 실제 API 실행으로 생성한 검증 예시입니다.

- 입력 여행일: `2026-03-15`
- 실행일: `2026-08-27`
- 옵션: `--cities 2`
- 결과: 제주·경주, Kakao 장소 10건, 근거 검사 10/10 통과

새로 실행하면 `{여행일}_raw.json`과 `{여행일}_travel_plan.md`가 이 폴더에 만들어집니다.
새 실행 결과는 실수로 개인정보나 예기치 않은 모델 출력을 공개하지 않도록 Git에서 제외합니다.
검증된 이 예시 1쌍만 예외적으로 추적합니다.

날씨·행사는 실시간 사실이 아니라 당시 LLM의 추정 결과입니다.
