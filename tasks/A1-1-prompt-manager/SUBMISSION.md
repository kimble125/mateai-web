## 보너스 구현

- 메뉴 8~10: JSON 저장·불러오기, 카테고리별 Markdown 내보내기
- 메뉴 11~13: 수정·삭제, 조회수 기록, 많이 쓴 프롬프트 정렬

저장 기능은 사용자가 메뉴에서 명시적으로 선택할 때만 동작합니다. 따라서 기본 상태에서
종료 시 초기화된다는 필수 요구사항과 충돌하지 않습니다.

## MateAI와의 연결 범위

- **사실**: 기본 데이터 5개는 MateAI 개발 과정에서 사용한 프롬프트를 정리한 것입니다.
- **해석**: 즐겨찾기(선언)와 조회수(행동)를 구분한 경험은 이후 사용자 신호 설계의 기초가 됩니다.
- **한계**: 이 과제 자체는 Python·Git 기초 증거입니다. ML 학습·RAG·MateAI 성능을 검증한 결과로 주장하지 않습니다.
