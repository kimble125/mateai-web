About MateAI

A travel companion that tells you what's checked

MateAI helps first-time visitors to Korea plan and chat in one place. AI can be wrong, so we show you which information was verified and which is only an estimate.

✅ What we check

  • Restaurant names in a trip plan are matched against Kakao Map search results.
  • Anything not found in the search results is flagged "not in search results".
  • If there's nothing to check, we say so. We never show a fake "pass".

⚠️ What we don't guarantee

  • Weather and events are AI estimates for that time of year.
  • Addresses, opening hours and prices can change. Check Naver Map or KakaoMap.
  • The train timetable in the delay demo is sample data, not live Korail data.

🔒 Privacy

Your chat stays in this browser tab (session storage) and is sent only to generate replies. We don't keep accounts or chat logs on a database. API keys live only on the server.

🛠️ How it's built

Plain HTML/CSS/JavaScript frontend, Python serverless functions on Vercel, an LLM API and Kakao/Naver local search.

You → js fetch('/api/chat' | '/api/travel') → Python checks your input → AI recommends · map search · AI writes → restaurant names checked → shown here
